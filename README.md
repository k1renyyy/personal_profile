# Kiren Portfolio

Kiren 的个人作品集网站，使用 Next.js、TypeScript、Tailwind CSS、Sanity 和 GSAP 构建。

## 本地运行

```bash
npm install
npm run dev
```

网站内容默认从 Sanity 的已发布数据读取；本地配置保存在未纳入 Git 的 `.env.local` 中。

## 项目来源

本项目早期工程底座基于 [mano-sudo/portfolio-v3](https://github.com/mano-sudo/portfolio-v3) 改造。原仓库当前未声明开源许可证，因此本仓库不将继承部分声明为原创或重新授权。后续个人内容、产品设计与界面改造由 Kiren 持续完成。
