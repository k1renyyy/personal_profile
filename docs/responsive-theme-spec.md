# 响应式与主题规格

## 全局基线

- 验收视口：390×844、430×932、768×1024、1024×768、1440×900、1920×1080。
- 首次访问为浅色；只保存用户主动选择的 `light | dark`，不读取系统主题。
- 页面不得产生横向滚动；键盘焦点可见；主要触摸目标不小于 36×36 px。
- `prefers-reduced-motion: reduce` 下停止持续循环和非必要入场、视差动画，内容保持完整可见。

## 区块规格

1. Hero：窄屏按标题、媒体、身份、说明顺序单列；图片保持主体焦点，文字允许自然换行；两种主题均保留背景光晕与文字对比。
2. About：文字先于三图；三图在窄屏保持可辨识的扇形叠放，宽屏为左右双栏；媒体均使用 Sanity 焦点和替代文本。
3. Experience：`lg` 以上保留滚动翻牌，以下使用 Tabs；卡片正文不裁切，深色主题中的背面卡片使用深色表面。
4. Projects：首页内展示三项；`lg` 以上为选择器加详情面板，以下按 Sanity 排序纵向阅读；不产生链接或详情路由。
5. Skills：两行能力条仅在允许动画时循环；深浅主题使用当前前景色与背景渐隐。
6. Testimonials：六条授权内容全部进入循环；窄屏卡片宽度不得超过可用视口；减少动态时停止循环并保持首组内容可读。
7. Contact：窄屏单列、宽屏双栏；邮箱、复制按钮和三个社交入口均可键盘操作，长地址不得造成横向溢出。

每次区块修改后先跑对应 Chromium 聚焦检查；发布门禁再跑三浏览器完整回归。
