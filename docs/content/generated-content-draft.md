## 5. 项目经历

### 多模态直播高光分析 Agent
- 个人角色： 独立完成产品定义、AI 工作流设计、效果验收与上线
- 项目年份： 2026
- 项目摘要： 将多模态直播内容转化为可解释、可复核的高光候选，帮助运营人员更快发现值得二次传播的内容。
- 项目详细介绍：
针对运营人员需要逐场观看直播、筛选高光素材效率低且容易遗漏的问题，我从真实内容工作流出发，定义高光识别标准、输入信号、候选输出和人工验收机制，独立设计并上线多模态直播高光分析 Agent。系统综合分析 ASR 文本、语义、音频变化、画面变化和弹幕反馈，对候选片段进行识别、解释和排序，再交由运营人员复核。通过持续分析人工验收结果，我迭代提示词、判断规则和筛选阈值，使工具从技术原型转化为团队实际使用的内容决策工具，并可通过配置适配不同活动。

- 项目亮点：
  1. 将“什么内容值得传播”拆解为可执行的高光标准、信号体系和验收规则，而不是直接依赖模型判断。
  2. 设计多模态分析工作流，融合 ASR、LLM、音频、画面和弹幕信号，对候选片段进行交叉验证和优先级排序。
  3. 建立 Human-in-the-loop 验收闭环，根据运营人员的通过、拒绝和遗漏结果持续调整提示词、规则与阈值。
  4. 将模型输出转化为运营人员可直接复核的候选清单，降低连续盯播成本，并保留最终人工判断。
  5. 通过配置化设计分离活动规则和分析流程，使同一套能力能够复用于不同直播及营销场景。
  6. 完成从问题定义、工作流设计、开发协作到部署验收和团队使用的完整落地。

### Nike × Adidas 赞助策略与经营表现分析
- 个人角色： 独立研究与数据分析
- 项目年份： 2026
- 项目摘要： 使用 Python 整合经营数据与体育赞助信息，对比 Nike 和 Adidas 的赞助策略、业务表现及战略差异。
- 项目详细介绍：
为理解体育赞助如何服务品牌增长与商业战略，我收集并整理 Nike 和 Adidas 的公开经营数据、财务资料及代表性赞助案例，使用 Python 完成数据清洗、指标计算、趋势分析和可视化。研究从经营表现与赞助布局两个维度展开，对比两家公司在不同时期的业务变化、资源投入重点和赞助策略，并分析品牌合作与整体经营方向之间的关系，最终形成结构化的策略判断与研究结论。

- 项目亮点：
  1. 使用 Python、pandas 和 Matplotlib 完成多来源数据清洗、指标计算、趋势对比和可视化。
  2. 建立统一对比框架，分析 Nike 与 Adidas 的核心经营指标和变化趋势。
  3. 整理两家公司在运动项目、运动员、球队及赛事等领域的赞助布局。
  4. 将财务表现与赞助策略结合，分析品牌资源配置背后的商业逻辑。
  5. 将分散的公开信息转化为结构化、可解释的策略分析结论。

### 网易七鱼智能客服 Agent 功能分析
- 个人角色： 独立 AI 产品研究与功能设计
- 项目年份： 2026
- 项目摘要： 围绕知识库覆盖不完整的电商客服场景，研究 AI Agent 如何理解复杂表达并通过多轮追问将用户问题澄清完整。
- 项目详细介绍：
针对传统智能客服依赖知识库和固定 Workflow、难以处理复杂自由表达的问题，我围绕电商退货退款场景，完成市场研究、用户画像、需求分析和竞品测试。研究重点是 AI 能否识别用户已经提供和仍然缺失的信息，在多轮对话中保持上下文，并根据新信息动态调整追问。我设计了 20 条测试 Case 和 8 个评价维度，对比网易七鱼、字节飞鸽与福客 AI 的产品路径和实际表现，并据此提出七鱼从固定知识匹配向动态问题澄清 Agent 升级的产品方向。

- 项目亮点：
  1. 从电商客服真实场景出发，识别知识库和固定 Workflow 无法覆盖的用户问题。
  2. 建立四类企业用户画像，梳理自由文本理解、信息缺口识别和多轮动态追问需求。
  3. 设计 20 条测试 Case 和 8 个评价维度，覆盖复杂表达、上下文保持、条件冲突及动态追问。
  4. 对比网易七鱼、字节飞鸽与福客 AI，分析传统客服 SaaS、平台原生客服和 AI Native Agent 三种产品路径。
  5. 提出“理解已有信息—识别缺失或冲突条件—动态追问—更新问题状态”的 Agent 功能链路。
  6. 将市场、用户、竞品和产品测试结论转化为明确的功能优先级与产品升级建议。
